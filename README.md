# Film Ratings

A responsive movie discovery site created for a digital marketing course. Open `index.html` locally or publish the repository with GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

Film ratings and short reviews are editorial selections for this project, not Rotten Tomatoes or audience scores. Movie poster images are loaded from TMDB's image service; fonts are loaded from Google Fonts, so an internet connection is needed for those assets.
